### Information Sources

All data used in this dissertation was generated in the Musculoskeletal Regenerative 
Engineering Lab by me from analysis of the following assays:

- Western Blotting
- Immunostaining
- RT-qPCR

The majority of the raw data are high resolution microscopy images taken using a widefield
fluorescent microscope using 4 fluorescent channels to visualize labeled proteins 
coupled with DIC or phase contrast to image PMMA nanofibers.
